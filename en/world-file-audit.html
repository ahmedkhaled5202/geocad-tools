Read a raster world file and pixel steps

Inspect six affine coefficients, pixel steps and determinant without loading the raster.

A small TFW, JGW or PGW world file contains the affine mapping from raster row and column positions to map coordinates. The script reports pixel-center position, horizontal/vertical step vectors and the transform determinant.

How to use

  1. Locate the world file such as map.tfw next to its related image.
  2. Run python world_file_audit.py map.tfw.
  3. Compare the first pixel-center coordinate with an expected mapped location.
  4. Inspect B/D components for rotation or skew.
  5. Check projection and units in other metadata or GIS: world files do not contain a CRS.

#!/usr/bin/env python3
"""Read six-value raster world file without loading raster pixels."""
import argparse
import math
from pathlib import Path

p = argparse.ArgumentParser(description=__doc__)
p.add_argument('file', help='World file e.g. image.tfw or image.jgw')
args = p.parse_args()
lines = Path(args.file).read_text(encoding='utf-8-sig').splitlines()
if len(lines) != 6:
    p.error('A world file must have exactly six numeric lines')
try:
    A, D, B, E, C, F = [float(value.strip()) for value in lines]
except ValueError:
    p.error('All six world-file values must be numbers')
if not all(math.isfinite(v) for v in (A,D,B,E,C,F)):
    p.error('Non-finite value found')
print('Pixel center at column=0,row=0:', C, F)
print('Horizontal pixel step (map units):', A, D)
print('Vertical pixel step (map units):', B, E)
print('Step magnitudes:', math.hypot(A,D), math.hypot(B,E))
print('Determinant:', A*E - B*D)
print('No CRS or physical units are stored in the world file.')

Illustrative example

With A=2, E=-2 and B=D=0, the reported pixel-step magnitude is two map units in each direction.

Limitations and verification

Does not read raster dimensions or infer CRS/units, and cannot prove the world file belongs to that image. A near-zero determinant indicates a degenerate transform; the report is not a full georeferencing quality check.

Reference specification or documentation

Open-source example: always test with a copy before real-world use.
