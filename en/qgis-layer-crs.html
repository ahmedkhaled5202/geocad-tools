Audit QGIS layer coordinate systems

List layer names, CRS identifiers and layer validity in a read-only report.

Before combining data from different sources, inspect the coordinate systems assigned to your layers. This script reads registered project layers and prints each name, CRS identifier and validity status without editing or reprojecting data.

How to use

  1. Open your project in QGIS 3.
  2. Open Python Console from the Plugins menu, then open its script editor.
  3. Open layer_crs.py in the editor or paste the complete code.
  4. Run the script and read the console output. It requires QGIS Python, not a normal Python interpreter.

Complete source code

Download code
from qgis.core import QgsProject

layers = list(QgsProject.instance().mapLayers().values())
if not layers:
    print("No layers loaded.")
for layer in sorted(layers, key=lambda item: item.name().casefold()):
    crs = layer.crs()
    identifier = crs.authid() or crs.description() or "Unknown/custom CRS"
    if not crs.isValid():
        identifier = "Invalid or missing CRS"
    status = "valid" if layer.isValid() else "invalid"
    print(f"{layer.name()} | {identifier} | {status}")
print(f"Total registered layers: {len(layers)}")

Illustrative example

Illustrative output: Roads | EPSG:32636 | valid. This is not a recommendation to use that CRS for your data.

Limitations and verification

Reports the assigned CRS; it cannot prove it was assigned correctly. Mixed coordinate systems are not inherently an error. Custom systems may use descriptions instead of EPSG identifiers. Hidden layers are included. Not run inside QGIS: compare with sample layer properties first.
