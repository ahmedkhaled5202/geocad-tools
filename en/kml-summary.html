Summarize KML placemarks and coordinate range

Count placemarks and coordinate tuples without uploading the KML file.

A KML file can hold points, paths and polygons in one exchange document. This report reads an ordinary local KML file, counts Placemark elements and summarizes coordinates present in coordinate tags, without network requests.

How to use

  1. Export an uncompressed .kml file, not a .kmz archive.
  2. Run python kml_summary.py map.kml.
  3. Review placemark count and valid coordinate tuples.
  4. Inspect malformed or out-of-range coordinates if flagged.
  5. Confirm the data visually in a suitable mapping program.

#!/usr/bin/env python3
"""Count KML placemarks and report lon/lat extent of coordinates tags."""
import argparse
import xml.etree.ElementTree as ET

p = argparse.ArgumentParser(description=__doc__)
p.add_argument('file', help='KML file (not KMZ)')
args = p.parse_args()
root = ET.parse(args.file).getroot()
local = lambda tag: tag.rsplit('}', 1)[-1]
placemarks = sum(local(e.tag) == 'Placemark' for e in root.iter())
points = []
invalid = 0
for element in root.iter():
    if local(element.tag) != 'coordinates' or not element.text:
        continue
    for part in element.text.split():
        fields = part.split(',')
        try:
            lon, lat = float(fields[0]), float(fields[1])
            if not (-180 <= lon <= 180 and -90 <= lat <= 90):
                invalid += 1
            else:
                points.append((lon, lat))
        except (ValueError, IndexError):
            invalid += 1
print('Placemarks:', placemarks)
print('Coordinate tuples in range:', len(points))
print('Invalid/out-of-range tuples:', invalid)
if points:
    print('Longitude extent:', min(x for x, _ in points), max(x for x, _ in points))
    print('Latitude extent:', min(y for _, y in points), max(y for _, y in points))
print('Does not expand NetworkLinks, external resources or KMZ files.')

Limitations and verification

Does not resolve NetworkLinks, remote resources, KMZ archives or live data. Placemark count is not vertex count. Extent covers only coordinates tags found in the file.
