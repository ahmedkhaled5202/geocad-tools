Inspect GeoJSON geometry types and extents

Count geometry types and inspect longitude/latitude ranges from a read-only report.

Received GeoJSON layers deserve a quick sanity check before they enter a mapping workflow. This tool reads a FeatureCollection, Feature or Geometry and reports geometry type counts, numeric positions and coordinate extents.

How to use

  1. Save the GeoJSON file as UTF-8.
  2. Run python geojson_geometry_audit.py layer.geojson.
  3. Compare the reported types with expected source layers.
  4. Review longitude and latitude ranges: standard GeoJSON positions are ordered lon,lat.
  5. Investigate outliers in a GIS rather than changing projections based solely on the report.

#!/usr/bin/env python3
"""Read GeoJSON and report geometry types and numeric lon/lat extent."""
import argparse
import json
import math
from collections import Counter

p = argparse.ArgumentParser(description=__doc__)
p.add_argument('file', help='GeoJSON file')
args = p.parse_args()
with open(args.file, encoding='utf-8-sig') as f:
    data = json.load(f)
if not isinstance(data, dict):
    p.error('Top-level GeoJSON value must be an object')
if data.get('type') == 'FeatureCollection':
    features = data.get('features')
    if not isinstance(features, list):
        p.error('FeatureCollection.features must be an array')
    geometries = [f.get('geometry') if isinstance(f, dict) else None for f in features]
elif data.get('type') == 'Feature':
    geometries = [data.get('geometry')]
else:
    geometries = [data]

def walk_geometry(g):
    if not isinstance(g, dict):
        yield None, None
        return
    kind = g.get('type')
    if kind == 'GeometryCollection':
        nested = g.get('geometries', [])
        if not isinstance(nested, list):
            yield 'invalid_geometry', None
        else:
            for item in nested:
                yield from walk_geometry(item)
        return
    yield kind or 'unknown', g.get('coordinates')

def positions(value):
    if isinstance(value, list):
        if len(value) >= 2 and all(isinstance(n, (int, float)) and not isinstance(n, bool) for n in value[:2]):
            x, y = value[:2]
            if math.isfinite(x) and math.isfinite(y):
                yield (x, y)
        else:
            for part in value:
                yield from positions(part)

counts = Counter()
allpoints = []
for geom in geometries:
    for kind, coords in walk_geometry(geom):
        counts[kind or 'null_geometry'] += 1
        allpoints.extend(positions(coords))
print('Features / top-level geometries:', len(geometries))
print('Geometry types:', dict(counts))
print('Valid numeric positions:', len(allpoints))
if allpoints:
    print('Longitude extent:', min(p[0] for p in allpoints), max(p[0] for p in allpoints))
    print('Latitude extent:', min(p[1] for p in allpoints), max(p[1] for p in allpoints))
    outside = sum(abs(x) > 180 or abs(y) > 90 for x, y in allpoints)
    print('Positions outside usual lon/lat bounds:', outside)
print('This is a quick audit, not full RFC 7946 validation.')

Illustrative example

A dataset with two Point features and a LineString can show Point: 2 and LineString: 1 plus the numeric coordinate extents.

Limitations and verification

Not a complete RFC 7946 or topology validator; it does not test polygon ring closure or self-intersections. Treats positions as standard lon/lat and does not reproject nonstandard data. Large files are read into memory.

Reference specification or documentation

Open-source example: always test with a copy before real-world use.
