راجع أنظمة إحداثيات طبقات QGIS

تقرير سريع بأسماء الطبقات ونظام الإحداثيات وحالة صلاحية كل طبقة.

قبل دمج بيانات من مصادر مختلفة، راجع أنظمة الإحداثيات المعرّفة للطبقات. هذا السكريبت يقرأ الطبقات المسجلة بالمشروع ويطبع الاسم ومعرّف CRS وحالة صلاحية الطبقة دون تعديلها أو إعادة إسقاطها.

طريقة الاستخدام

  1. افتح مشروعك داخل QGIS 3.
  2. افتح Python Console من قائمة Plugins ثم افتح محرر السكريبتات.
  3. افتح ملف layer_crs.py في المحرر أو الصق الكود كاملًا.
  4. شغّل الكود واقرأ التقرير في وحدة التحكم. الكود يحتاج بيئة QGIS، وليس Python العادي.

الكود الكامل

تنزيل الكود
from qgis.core import QgsProject

layers = list(QgsProject.instance().mapLayers().values())
if not layers:
    print("No layers loaded.")
for layer in sorted(layers, key=lambda item: item.name().casefold()):
    crs = layer.crs()
    identifier = crs.authid() or crs.description() or "Unknown/custom CRS"
    if not crs.isValid():
        identifier = "Invalid or missing CRS"
    status = "valid" if layer.isValid() else "invalid"
    print(f"{layer.name()} | {identifier} | {status}")
print(f"Total registered layers: {len(layers)}")

مثال توضيحي

قد يظهر سطر مثل: Roads | EPSG:32636 | valid. هذه نتيجة توضيحية فقط وليست توصية بنظام إحداثيات معين.

الحدود والتحقق

يعرض CRS المعرّف ولا يثبت أن البيانات أُسند لها النظام الصحيح. اختلاف الأنظمة ليس خطأ في حد ذاته. الأنظمة المخصصة قد تظهر بوصفها بدل EPSG. الطبقات غير المرئية أيضًا مشمولة. لم يُشغّل الكود داخل QGIS؛ قارِن التقرير بخصائص طبقات تجريبية أولًا.

التوثيق أو المعيار المرجعي

الكود مفتوح المصدر، ويجب تجربة نسخة من الملفات قبل استخدامه في مشروع حقيقي.
