GeoJSON

حصر حقول خصائص GeoJSON والقيم الناقصة

اعرف أسماء الحقول ومدى اكتمال قيمها عبر المعالم دون أي تعديل.

تختلف طبقات GeoJSON أحيانًا في حقولها حتى عندما تحمل النوع الهندسي نفسه. هذه الأداة تسرد أسماء الحقول، وعدد المعالم التي تحتوي كل حقل، وعدد القيم غير الفارغة null. يفيد التقرير عند تصميم الجداول أو الاتفاق على مخطط تسليم البيانات.

طريقة الاستخدام

  1. جهّز FeatureCollection بصيغة GeoJSON.
  2. نفّذ python geojson_field_inventory.py parcels.geojson.
  3. اقرأ الأعمدة Field وpresent وnon-null.
  4. راجع الحقول الاختيارية والمفقودة قبل كتابة قواعد قاعدة البيانات.
  5. النتيجة لا تعدّل أي قيمة ولا تخبرك إن كانت دلالات الحقول صحيحة.

الكود الكامل

تنزيل الكود
#!/usr/bin/env python3
"""Summarize GeoJSON feature attribute keys and null coverage."""
import argparse
import json
from collections import Counter

p = argparse.ArgumentParser(description=__doc__)
p.add_argument('file', help='GeoJSON FeatureCollection')
args = p.parse_args()
with open(args.file, encoding='utf-8-sig') as f:
    data = json.load(f)
if not isinstance(data, dict) or data.get('type') != 'FeatureCollection':
    p.error('Expected a FeatureCollection object')
features = data.get('features')
if not isinstance(features, list):
    p.error('Expected features array')
seen = Counter()
not_null = Counter()
for i, feat in enumerate(features, start=1):
    if not isinstance(feat, dict) or feat.get('type') != 'Feature':
        print(f'Warning: entry {i} is not a Feature')
        continue
    props = feat.get('properties')
    if props is None:
        props = {}
    if not isinstance(props, dict):
        print(f'Warning: feature {i} has non-object properties')
        continue
    for name, value in props.items():
        seen[name] += 1
        not_null[name] += value is not None
print('Feature entries:', len(features))
print('Field | present | non-null')
for name in sorted(seen, key=str.casefold):
    print(f'{name} | {seen[name]} | {not_null[name]}')
print('No input files were changed.')

مثال توضيحي

إذا كان حقل parcel_id موجودًا في 10 معالم بينما 8 فقط غير فارغة، يظهر present=10 وnon-null=8.

الحدود والتحقق

لا يتحقق من نوع قيمة الحقل أو تنسيق الأرقام ولا يعتبر السلاسل النصية الفارغة مساوية لـnull. يعرض جميع المفاتيح كما جاءت، بما فيها الاختلاف في حالة الأحرف. يحتاج FeatureCollection، وقد يحتاج ملف كبير إلى ذاكرة كافية.

التوثيق أو المعيار المرجعي

الكود مفتوح المصدر، ويجب تجربة نسخة من الملفات قبل استخدامه في مشروع حقيقي.
