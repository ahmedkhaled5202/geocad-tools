فحص إحداثيات CSV قبل إدخالها إلى GIS

تحقق من قيم X وY المفقودة والتكرارات والامتداد المكاني بدون تعديل الملف.

ملفات نقاط الرفع المساحي قد تحتوي صفوفًا ناقصة أو قيمًا غير رقمية أو مواقع مكررة. يقدم هذا السكريبت فحصًا أوليًا للعمودين X وY، ويطبع رقم صف كل مشكلة. يترك الملف كما هو حتى تراجع النتائج قبل استيراده إلى QGIS أو برنامج CAD.

طريقة الاستخدام

  1. حضّر ملف CSV بترميز UTF-8 وله صف عناوين، مثل X,Y,Name.
  2. حمّل السكريبت على جهاز عليه Python 3.9 أو أحدث.
  3. نفذ python csv_coordinate_audit.py points.csv؛ غيّر أسماء الحقول باستخدام --x Easting --y Northing عند الحاجة.
  4. راجع أسطر المشاكل وحدود X وY، ثم صحّح نسخة من البيانات الأصلية.
  5. تأكد بشكل مستقل من نظام الإحداثيات والوحدات لأنهما غير مخزنين بالضرورة في CSV.

الكود الكامل

تنزيل الكود
#!/usr/bin/env python3
"""Check numeric X/Y columns in a UTF-8 CSV. Never modifies the input file."""
import argparse
import csv
import math
from collections import Counter

p = argparse.ArgumentParser(description=__doc__)
p.add_argument('file', help='UTF-8 CSV file')
p.add_argument('--x', default='X', help='X column name (default: X)')
p.add_argument('--y', default='Y', help='Y column name (default: Y)')
args = p.parse_args()

seen = set()
issues = Counter()
xs, ys = [], []
with open(args.file, newline='', encoding='utf-8-sig') as f:
    reader = csv.DictReader(f)
    if not reader.fieldnames or args.x not in reader.fieldnames or args.y not in reader.fieldnames:
        p.error(f'Expected columns {args.x!r} and {args.y!r}; found {reader.fieldnames!r}')
    total = 0
    for line, row in enumerate(reader, start=2):
        total += 1
        try:
            x = float(row[args.x])
            y = float(row[args.y])
            if not math.isfinite(x) or not math.isfinite(y):
                raise ValueError('non-finite')
        except (ValueError, TypeError, OverflowError):
            issues['invalid_or_missing_xy'] += 1
            print(f'Row {line}: invalid or missing X/Y')
            continue
        pair = (x, y)
        if pair in seen:
            issues['duplicate_xy'] += 1
            print(f'Row {line}: repeated coordinate pair')
        seen.add(pair)
        xs.append(x); ys.append(y)
print(f'Total rows: {total} | Numeric XY: {len(xs)}')
print('Issues:', dict(issues))
if xs:
    print(f'Extent X: {min(xs):g} .. {max(xs):g}')
    print(f'Extent Y: {min(ys):g} .. {max(ys):g}')
print('Coordinate reference system and units: NOT checked')

مثال توضيحي

ملف فيه 4 صفوف، أحدها X فارغ والآخر يكرر نفس زوج الإحداثيات، سيظهر سطر للصف الناقص وسطر للتكرار مع إجمالي صفوف الملف.

الحدود والتحقق

السكريبت لا يتحقق من CRS أو مواقع النقاط الفعلية على الأرض، ولا يعتبر تكرار زوج X/Y خطأ مؤكدًا. لا يطابق النقاط المتقاربة؛ فهو يقارن قيم الأرقام كما هي. للأعداد العشرية استخدم النقطة وليس الفاصلة. النتيجة فحص مبدئي وليست اعتمادًا مساحيًا.

التوثيق أو المعيار المرجعي

الكود مفتوح المصدر، ويجب تجربة نسخة من الملفات قبل استخدامه في مشروع حقيقي.
