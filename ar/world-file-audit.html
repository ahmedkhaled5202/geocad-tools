افهم World File للصورة الجغرافية

اقرأ ست قيم التحويل المكاني للصورة واحسب خطوة البكسل والدوران دون فتح الراستر.

ملف TFW أو JGW أو PGW صغير الحجم لكنه يحدد كيف تتحول إحداثيات صفوف وأعمدة الصورة إلى إحداثيات الخريطة. يعرض هذا السكريبت مصفوفة الخطوة والإحداثيات عند مركز أول بكسل، مع تقدير مقدار خطوة البكسل واختبار المحدد الرياضي.

طريقة الاستخدام

  1. ضع ملف world مثل map.tfw إلى جانب الصورة المرتبطة به.
  2. نفذ python world_file_audit.py map.tfw.
  3. قارن Pixel center بقيم إحداثيات منطقة التصوير المتوقعة.
  4. لاحظ الخطوتين الأفقية والرأسية؛ قيم B وD غير الصفرية قد تعني دورانًا أو قصًا.
  5. تحقق من CRS في ملفات أخرى أو في برنامج GIS، فهو غير موجود داخل world file وحده.

الكود الكامل

تنزيل الكود
#!/usr/bin/env python3
"""Read six-value raster world file without loading raster pixels."""
import argparse
import math
from pathlib import Path

p = argparse.ArgumentParser(description=__doc__)
p.add_argument('file', help='World file e.g. image.tfw or image.jgw')
args = p.parse_args()
lines = Path(args.file).read_text(encoding='utf-8-sig').splitlines()
if len(lines) != 6:
    p.error('A world file must have exactly six numeric lines')
try:
    A, D, B, E, C, F = [float(value.strip()) for value in lines]
except ValueError:
    p.error('All six world-file values must be numbers')
if not all(math.isfinite(v) for v in (A,D,B,E,C,F)):
    p.error('Non-finite value found')
print('Pixel center at column=0,row=0:', C, F)
print('Horizontal pixel step (map units):', A, D)
print('Vertical pixel step (map units):', B, E)
print('Step magnitudes:', math.hypot(A,D), math.hypot(B,E))
print('Determinant:', A*E - B*D)
print('No CRS or physical units are stored in the world file.')

بيانات اختبار جاهزة

البيانات تجريبية وغير مرتبطة بمشروع فعلي؛ راجع التقرير قبل استخدام الأداة على ملفاتك.

تنزيل ملف بيانات للتجربة

أمر تجربة الأداة على الملف

python world_file_audit.py world-file-audit.tfw

مثال توضيحي

عندما تكون A=2 وE=-2 وB=D=0، تكون خطوة البكسل بمقدار وحدتين من وحدات الخريطة لكل اتجاه.

الحدود والتحقق

السكريبت لا يقرأ عدد البكسلات ولا نظام الإحداثيات ولا الوحدات ولا يطابق الصورة بالملف. قيمة determinant القريبة من الصفر تدل على تحويل متدهور حسابيًا، لكنها ليست فحصًا شاملاً لجودة المحاذاة.

التوثيق أو المعيار المرجعي

الكود مفتوح المصدر، ويجب تجربة نسخة من الملفات قبل استخدامه في مشروع حقيقي.
